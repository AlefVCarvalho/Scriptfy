# Scriptfy

Aplicativo mobile para adicionar, editar, remover e tocar músicas

- `backend/`: API em Java + Spring Boot + JPA/MySQL
- `frontend/`: App React Native + Expo (em breve)

1. Execute `backend/sql/scriptfy.sql` no MySQL.
2. Copie `backend/src/main/resources/application-local.properties.example` para `application-local.properties` e coloque sua senha.
3. Na pasta `backend`: `./mvnw spring-boot:run` (Windows: `.\mvnw spring-boot:run`)
